3. AVL TREE IMPLEMENTATION (Lines 35-196)
================================================================================

WHAT IS AVL TREE?
-----------------
Self-balancing Binary Search Tree where the height difference between
left and right subtrees (balance factor) is at most 1 for every node.

NODE STRUCTURE:
---------------
struct AVLNode {
    string donorName;    // Key for searching
    int donorID;         // Associated donor ID
    int height;          // Height of subtree rooted at this node
    AVLNode *left;       // Left child pointer
    AVLNode *right;      // Right child pointer
};

CLASS: DonorBST
---------------
PRIVATE METHODS:

1. getHeight(AVLNode *node)
   - Returns height of node (0 if null)
   - Used for balance factor calculation

2. getBalanceFactor(AVLNode *node)
   - Returns: height(left) - height(right)
   - Balanced if result is -1, 0, or 1

3. updateHeight(AVLNode *node)
   - Recalculates height after rotations
   - height = 1 + max(left_height, right_height)

4. rightRotate(AVLNode *y)
   - Performs right rotation for LL and LR cases
   - Returns new root of subtree
   
   BEFORE:        AFTER:
       y            x
      / \          / \
     x   T3  =>  T1   y
    / \              / \
   T1  T2          T2  T3

5. leftRotate(AVLNode *x)
   - Performs left rotation for RR and RL cases
   - Returns new root of subtree
   
   BEFORE:        AFTER:
     x              y
    / \            / \
   T1  y    =>    x   T3
      / \        / \
     T2  T3    T1  T2

6. balance(AVLNode *node)
   - Checks balance factor and applies appropriate rotation
   - Four cases handled:
     * LL Case (balanceFactor > 1, left child left-heavy): rightRotate
     * LR Case (balanceFactor > 1, left child right-heavy): leftRotate left, rightRotate
     * RR Case (balanceFactor < -1, right child right-heavy): leftRotate
     * RL Case (balanceFactor < -1, right child left-heavy): rightRotate right, leftRotate

7. insertHelper(AVLNode *node, string name, int id)
   - Recursive BST insertion
   - Calls balance() after insertion to maintain AVL property

8. searchHelper(AVLNode *node, string name)
   - Recursive BST search
   - Returns node if found, nullptr otherwise

PUBLIC METHODS:

1. insert(string name, int id)
   - Public wrapper for insertHelper
   - Inserts donor name with associated ID

2. search(string name)
   - Public wrapper for searchHelper
   - Returns donor ID if found, -1 otherwise

MENU OPTION: 8 (Search Donor by Name)

WHAT IS LRU CACHE?
------------------
Cache that stores recently accessed items. When full, evicts
Least Recently Used item. Combines doubly linked list + hash map.

CLASS: LRUCache
---------------
PRIVATE MEMBERS:

- int capacity (max items = 10)
- list<pair<int, Donor*>> dll (doubly linked list)
  * Front = Most Recently Used
  * Back = Least Recently Used
- unordered_map<int, iterator> cache (for O(1) access)

PUBLIC METHODS:

1. LRUCache(int cap)
   - Constructor sets capacity

2. get(int donorID)
   - Returns Donor* if in cache, nullptr otherwise
   - On cache hit: moves item to front (most recent)
   - MENU OPTION: 15 (View Cache)
   
   Algorithm:
   a) Check if donorID in hash map
   b) If not found, return nullptr (cache miss)
   c) If found:
      - Get iterator from hash map
      - Remove from current position
      - Insert at front
      - Update hash map with new iterator
      - Return Donor*

3. put(int donorID, Donor* donor)
   - Adds donor to cache
   - Evicts LRU if cache full
   
   Algorithm:
   a) If donorID already exists, remove old entry
   b) If cache full, remove back (LRU) and erase from map
   c) Insert new entry at front
   d) Update hash map with iterator

4. displayCache()
   - Shows all cached donors (most recent first)

WHAT IS UNION-FIND?
-------------------
Data structure to manage disjoint sets. Supports two operations:
- Find: Which set does element belong to?
- Union: Merge two sets

CLASS: DonorUnionFind
---------------------
PRIVATE MEMBERS:

- unordered_map<int, int> parent (donorID -> parent donorID)
- unordered_map<int, int> rank (donorID -> tree height)

PUBLIC METHODS:

1. makeSet(int donorID)
   - Creates new set with single element
   - parent[id] = id (self-parent)
   - rank[id] = 0

2. find(int x)
   - Returns root of set containing x
   - Uses PATH COMPRESSION optimization
   
   Path Compression:
   - During find, make every node point directly to root
   - Flattens tree for faster future finds
   
   Before find(4): 1 <- 2 <- 3 <- 4
   After find(4):  1 <- 2, 1 <- 3, 1 <- 4

3. unionSets(int x, int y)
   - Merges sets containing x and y
   - Uses UNION BY RANK optimization
   
   Union by Rank:
   - Attach smaller tree under larger tree
   - Keeps trees shallow
   
   If rank[rootX] < rank[rootY]: parent[rootX] = rootY
   If rank[rootX] > rank[rootY]: parent[rootY] = rootX
   If equal: parent[rootY] = rootX, rank[rootX]++

4. areConnected(int x, int y)
   - Returns true if x and y in same set
   - MENU OPTION: 17

5. displayNetworks()
   - Groups all donors by their root
   - Shows connected components
   - MENU OPTION: 16

INTEGRATION:

10. DIJKSTRA'S ALGORITHM - SHORTEST PATH (Lines 1006-1144)
================================================================================

WHAT IS DIJKSTRA'S?
-------------------
Algorithm to find shortest path from source to all vertices
in a weighted graph with non-negative edges.

EDGE STRUCTURE:
---------------
struct Edge {
    int destination;
    int distance;
};

CLASS: BloodDeliveryGraph
-------------------------
PRIVATE MEMBERS:

- int numLocations
- vector<vector<Edge>> adjList (adjacency list)
- vector<string> locationNames

PUBLIC METHODS:

1. BloodDeliveryGraph(int V)
   - Constructor initializes V locations
   - MENU OPTION: 12 (Setup)

2. addLocation(int index, string name)
   - Sets location name

3. addRoute(int from, int to, int distance)
   - Adds bidirectional edge to adjacency list

4. dijkstra(int source, int destination)
   - Returns vector of vertex indices (path)
   
   Algorithm:
   a) Initialize:
      - dist[source] = 0, all others = INT_MAX
      - parent[] = -1 (for path reconstruction)
      - visited[] = false
      - Priority queue with (distance, vertex) pairs
   
   b) Add (0, source) to priority queue
   
   c) While queue not empty:
      - Extract vertex u with minimum distance
      - If already visited, skip
      - Mark u as visited
      - For each neighbor v of u:
        * If dist[u] + weight(u,v) < dist[v]:
          - Update dist[v]
          - Set parent[v] = u
          - Add (dist[v], v) to queue
   
   d) Reconstruct path using parent array

5. displayShortestPath(int source, int destination)
   - Shows route and total distance
   - MENU OPTION: 13 (Find Route)

6. displayAllRoutes()
   - Shows all connections in network

11. PRIORITY QUEUE - MIN HEAP (Lines 1146-1310)
================================================================================

WHAT IS MIN HEAP?
-----------------
Complete binary tree where parent has higher priority (lower value)
than children. Root always has highest priority.

CLASS: PatientQueue
-------------------
PRIVATE MEMBERS:

- vector<Patient> heap (dynamic array)

PRIVATE METHODS:

1. hasHigherPriority(const Patient& p1, const Patient& p2)
   - Compares two patients for priority
   
   Priority Order (EDF - Earliest Deadline First):
   a) Lower urgency number = higher priority (1 > 2 > 3)
   b) If urgency equal: earlier deadline = higher priority
   c) If no deadline (0): treated as lowest priority

2. bubbleUp(int index)
   - Moves newly added element up to correct position
   - Compares with parent, swaps if higher priority
   - Recursively continues until heap property satisfied

3. bubbleDown(int index)
   - Moves root element down after dequeue
   - Compares with children, swaps with higher priority child
   - Recursively continues until heap property satisfied

PUBLIC METHODS:

1. PatientQueue()
   - Default constructor (vector auto-initializes)

2. isEmpty()
   - Returns heap.empty()

3. isFull()
   - Always returns false (vector grows dynamically)

4. enqueue(Patient p)
   - Adds patient to heap
   - MENU OPTION: 5
   
   Algorithm:
   a) Add patient to end of vector
   b) Call bubbleUp on last index

5. dequeue()
   - Removes and returns highest priority patient
   - MENU OPTION: 7
   
   Algorithm:
   a) Save root (highest priority)
   b) Move last element to root
   c) Remove last element
   d) Call bubbleDown on root
   e) Return saved patient

6. peek()
   - Returns highest priority patient without removing

7. displayQueue()
   - Shows all patients with urgency and deadline info
   - MENU OPTION: 6

8. getSize()
   - Returns heap.size()
